# “我的申请”列表布局修复设计

## 背景与根因

“我的申请”页面把 Ant Design Vue 的 `a-button` 同时用作整张申请卡片。组件库按钮自带固定高度、行高和单行文本约束，与列表项中“标题 + 时间”的两行结构冲突，导致内容被压扁、标题和时间挤在一起，状态标签也缺少稳定的垂直对齐。

## 设计目标

- 左侧信息区采用两行布局：申请标题在上，创建时间在下。
- 右侧状态标签垂直居中，并与左侧信息保持清晰间距。
- 整张卡片可点击，支持键盘聚焦及 Enter/Space 激活。
- 鼠标悬停和键盘聚焦时提供明确但克制的视觉反馈。
- 窄屏下标题可换行，状态标签不挤压或覆盖正文。

## 实现方案

在 `ApprovalMyRequests.vue` 中将承担卡片角色的 `a-button` 替换为原生 `button type="button"`。保留当前路由跳转逻辑、状态映射、筛选和数据加载逻辑，仅调整列表项语义结构及页面局部样式。

卡片使用横向 Flex 布局：左侧 `.request-info` 可收缩并纵向排列标题与时间；右侧状态标签固定收缩策略。卡片取消浏览器默认按钮外观，设置自动高度、正常换行、合理内边距、边框、圆角、悬停背景和可见焦点轮廓。小屏断点下仍保持信息清晰，必要时允许标题换行。

## 不在范围内

- 不修改审批接口、数据结构或状态含义。
- 不重构其他审批列表页面。
- 不改变筛选器、返回按钮或“发起申请”按钮。
- 不引入新的 UI 依赖或全局视觉主题。

## 验收与测试

- 增加端到端回归检查，使用一条申请数据验证：卡片高度足以容纳两行内容、时间位于标题下方、状态标签位于右侧且不重叠。
- 验证整行按钮可通过键盘聚焦并用 Enter 进入申请详情。
- 运行相关 Playwright 测试、TypeScript 类型检查和前端生产构建。
- 在本地运行页面上进行桌面尺寸视觉复核，并确认控制台无新增错误。
