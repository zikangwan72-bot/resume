# Enterprise AI Suite 离线 Web 原型包设计

## 目标

把当前真实系统的全部主要 Web 页面整理为可交付的离线原型包，放到桌面并压缩为 ZIP。

## 交付结构

- `static/desktop/`：1440×900 桌面端页面截图。
- `static/mobile/`：390×844 手机端页面截图。
- `dynamic/index.html`：无需服务器即可运行的交互式原型导航器。
- `README.md`：页面范围、打开方式和验收说明。
- `page-inventory.csv`：页面名称、模块、路由及截图文件映射。

## 页面范围

登录、工作台、招聘中心、学生投递、招聘管理、资产管理、审批首页、我的申请、发起申请、待我审批、我已审批、流程应用、流程编辑、员工与角色、流程监控、通知中心、AI运行记录、审计日志、个人资料和服务台占位页。

资产管理额外覆盖运营总览、资产台账、盘点工作台、异常处置、新建资产和新建盘点任务等关键状态。

## 动态原型

动态原型采用真实截图作为页面画布，支持：

- 按模块筛选页面。
- 切换桌面端和手机端。
- 上一页、下一页和业务流程导航。
- 点击侧边页面目录快速跳转。
- 显示原系统路由、页面说明和测试重点。

原型只用于展示和评审，不连接数据库，不产生业务数据。

## 验收标准

- HTML 可直接双击打开。
- 所有截图在离线状态下正常显示。
- 桌面和手机切换有效。
- 页面清单覆盖所有定义的主要路由和资产关键状态。
- ZIP 可正常解压，目录结构完整。
